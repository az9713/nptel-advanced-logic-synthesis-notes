3. Size a decoder path and choose a circuit family

The execution slice's decode output must drive both its data selector and a branch that reports the active instruction. If we enlarge the NAND blindly, the input stage may slow down more than the output speeds up. The sizing problem becomes tractable once the path's topology, input budget, and external load are fixed.

Logical effort and optimal stage effort L06 05:08 · L06 21:03

For a logic stage, choose a reference inverter of the same output drive. The ratio of the stage's input capacitance to the reference inverter's input capacitance defines logical effort \(g\). The ratio \(h=C_{out}/C_{in}\) of total load capacitance to input capacitance is electrical effort. In normalized time units, the stage delay is \(d=gh+p\), where \(p\) models size-independent intrinsic delay and \(gh\) is effort delay. A unit inverter with NMOS width one and PMOS width two has total input width three. In an equal-drive two-input NAND, each series NMOS has width two and each PMOS has width two. The NAND's input width per pin is four, giving \(g=4/3\) in this model. The sizing argument assumes resistance inversely proportional to width and capacitance proportional to width.

Consider a path of \(N\) stages with stage logical efforts \(g_i\), the last of which drives a fixed on-path load. Define the branch effort \(b_i\) as total output load divided by on-path load at stage \(i\). The product of the electrical efforts telescopes: each on-path capacitance cancels the next stage's input capacitance. With \(G=\prod_i g_i\), \(B=\prod_i b_i\), and \(H\) the ratio of final on-path load to first input capacitance, the product of the positive stage efforts \(f_i=g_i h_i\) is \(F=GBH\). Total normalized delay is \(D=\sum_i f_i+\sum_i p_i\). The arithmetic–geometric mean inequality gives \(\sum_i f_i\ge N F^{1/N}\), with equality when every \(f_i=F^{1/N}\). This is an optimum for continuous sizing, fixed branch ratios, and the stated delay model.

For a NAND followed by an inverter, set \(H=12\) and take a fixed branch effort of two at the NAND output. Then \(F=(4/3)(2)(12)=32\) and both optimal efforts are \(\sqrt{32}\approx5.66\). If the NAND and inverter parasitics are two and one, respectively, \(D\approx14.31\). The last inverter's input is the final load divided by \(5.66\), or about \(2.12\) times the NAND input capacitance. The NAND sees twice that input as its total load. It has effort \((4/3)(2)(2.12)\approx5.66\), checking both ends of the sizing calculation. If the off-path capacitance is fixed independently of the candidate size, the branch ratio varies with that size. Then substitute the actual load into each stage delay before optimizing. Sutherland and Sproull, Logical Effort

Selecting the number of stages adds a tradeoff. With one inverter driving an electrical effort of \(64\), the model gives delay \(65\). Three geometrically sized inverters with the same polarity have effort four each and total delay \(15\). Five have total delay \(5(64^{1/5}+1)\approx16.49\). Gates come in discrete drive strengths, their rising and falling delays differ, and real branching and wires change the optimum. Compare candidate implementations using the same input loading, external load, transition requirements, and clock contract. L06 44:00

The four-to-sixteen decoder example makes the branching cost concrete. One address literal feeds eight four-input NANDs of equal size. Use one input inverter, one four-input NAND, and one output inverter on the chosen path. A four-input NAND uses four series NMOS devices each sized to width four and PMOS devices of width two. Its input capacitance is six width units per pin, giving \(g=2\) against the three-unit inverter. An input budget of ten capacitance units and 32 bit cells of three units each give \(H=96/10=9.6\) and \(B=8\). Thus \(F=2\cdot8\cdot9.6=153.6\). With parasitics \(1+4+1\), the three-stage minimum is \(3(153.6)^{1/3}+6\approx22.07\) normalized delay units. The eight loads enter \(B\) once. Including them in \(H\) as well would charge for the same fanout twice. L06 45:18 · L06 47:14

The highlighted sizes come from working backward. Write the desired effort as \(f_*=153.6^{1/3}\approx5.36\). The final inverter sees 96 units, so its input is \(96/f_*\approx17.9\). One NAND input is \(2(17.9)/f_*\approx6.7\). The address inverter drives eight such inputs, so its implied input size is \(8(6.7)/f_*\approx10\). That recovers the input budget. L06 48:27

The ring-oscillator slide gives a separate use of the delay unit. Each inverter in an odd-\(N\) ring drives one identical inverter, so \(g=h=p=1\) and its modeled delay is \(2\tau\), where \(\tau\) is the process time unit. A transition traverses the loop and returns with opposite polarity, so a full period requires two passes, about \(4N\tau\). If a 31-stage ring oscillates around 200 MHz as on the slide, the effective average stage delay is \(1/(2\cdot31\cdot200\,\mathrm{MHz})\approx80.6\) ps. Under this model that corresponds to \(\tau\approx40.3\) ps. Extra measurement loading or unequal rise and fall delays can shift the result. L06 17:47

Ratioed, dynamic, and domino logic L07 08:01 · L07 20:01

Skewing a static gate's pull-up relative to its pull-down favors one transition at the expense of the other and changes the input switching point. In ratioed pseudo-NMOS logic, a weak PMOS is always on. An enabled pull-down must sink its current while holding the output within the low-level limit. In a resistive approximation with pull-up resistance \(R_p\) and pull-down resistance \(R_n\), low output is \(V_{DD}R_n/(R_p+R_n)\) and steady current is \(V_{DD}/(R_p+R_n)\). Requiring a low of at most \(0.1V_{DD}\) forces \(R_p\ge9R_n\). That same weak pull-up charges the output slowly after the pull-down releases. The topology saves devices in a wide gate, while imposing ratio-dependent noise margin and nonzero static dissipation in the low state.

A dynamic gate replaces the always-on pull-up with a clocked precharge device. The dynamic node precharges high. Evaluation either enables a pull-down or leaves the node high by storing charge. During evaluation a discharge cannot be undone until the next precharge. Driving a second dynamic gate directly from a first can discharge the second prematurely because the first starts high. A static inverter after the dynamic node produces an output that starts low and can rise during evaluation. This domino arrangement supports monotone cascading of the single-rail stages. Complemented inputs, dual rails, or different clocking can extend the set of realizable functions. L07 32:00

A footed stage puts a clock-controlled NMOS below its evaluate network. During precharge the footer isolates ground even if the data inputs enable the evaluate network. During evaluation it adds series resistance. A footless stage can trade away that resistance only when the input timing prevents contention during precharge. Dual-rail domino provides both polarities using two evaluate networks. For an AND output, one rail detects both inputs high and the other detects at least one input low using the complementary input rails. The driving rails must follow the precharge and monotonic evaluation protocol. L07 24:01 · L07 36:01

Read the dual-rail outputs in the order (true, false). The slide shows \(00\) during precharge, \(10\) for evaluated one, and \(01\) for evaluated zero. \(11\) is invalid. During a valid evaluation exactly one output rises. For a dual-rail XOR the true network evaluates on the two differing input combinations and the false network on the two equal combinations. Each network uses asserted rails as positive inputs, so its output can stay monotone even though single-rail XOR is not a monotone Boolean function. L07 36:40

The evaluate phase has analog failure modes. A charged capacitance \(C_d\) connected to an uncharged internal capacitance \(C_i\) shares charge. With no leakage or keeper current during redistribution, its new common voltage is \(V_{DD}C_d/(C_d+C_i)\). If \(C_i=C_d/2\), the voltage drops to \(2V_{DD}/3\) despite the absence of a complete discharge path to ground. A weak feedback keeper replenishes leakage and opposes a droop, but also fights a valid discharge until feedback releases it. The execution slice's timing contract would have to include the precharge/evaluate protocol, clock load, minimum evaluation conditions, and noise limits before using dynamic logic. L07 44:01

Laboratory and solved problems

Run python code/lab.py sizing to check both stage efforts, the normalized delay, and the charge-sharing result. This compares original model values and has no dependency on a particular process library.

  1. When does a branch increase optimum delay? With fixed two-stage topology and a fixed branch multiplier of two, \(F\) doubles. The best effort component increases by \(\sqrt2\), while the assumed parasitic sum is unchanged. That establishes a path comparison when the branch ratio really stays fixed.
  2. Can a dynamic network tolerate a momentary incorrect pull-down enable? Once it discharges, an output stored only as charge cannot recover in the evaluate phase. A short glitch may cause a smaller droop if discharge is incomplete. Correctness depends on input monotonicity, circuit noise margin, and the circuit's transient response.
